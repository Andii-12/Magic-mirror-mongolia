╔══════════════════════════════════════════════════════════════════════════════╗
║                              KEY POINTS                                      ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. System continuously checks distance from sensor
2. When person is close (≤20cm) for 3 times → Start recognition
3. Camera captures photo → Detects face → Recognizes person
4. If recognized → Save photo, turn on lights, show on display
5. If not recognized → Treat as guest
6. When person moves away → Turn off lights, wait 5s, reset
